# AI Dashboard

A modern and scalable AI Dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Features
- Modern UI/UX
- Responsive Design
- AI Agent Management
- Analytics Dashboard
- Authentication
- Real-time Monitoring
- Dark/Light Mode

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- React
- Vercel
